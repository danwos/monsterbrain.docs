# Changes

`Ctrl 2` lists everything that changed in the folder since a chosen point
({need}`DEC_CHANGES_ON_FOLDERS`):

| Since | Compares with |
|---|---|
| uncommitted | the last commit |
| today, this week, this month | the last commit before that date |

Changes are grouped by folder with counts. `j` and `k` (or `↓` `↑`) step to
the next and previous change; each opens its diff.

```{figure} ../_static/screens/changes-markdown.webp
:alt: The change view with five changed files and the rendered diff of a Markdown file

Changed files grouped by folder; a Markdown diff, rendered – **Side by side** and **Text** show it differently.
```

## Diffs rendered for the file type

| Type | Diff |
|---|---|
| Markdown | rendered before and after, or text |
| HTML | before and after side by side |
| `.po` | the changed entries only |
| Code, JSON, YAML | text |
| Images, PDF | before and after side by side |
