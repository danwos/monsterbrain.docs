Produkt¶

Entscheidung: Eine Desktop-App, kein Server, den man von Hand startet DEC_DESKTOP_APP
status: approved
decided: 2026-10-20
reason: Die App startet, überwacht und beendet intern alles, was sie braucht; keine Konsole.
alternatives: ein lokaler Server, der im Browser geöffnet wird.
Entscheidung: Layout: Baum links, Inhalt in der Mitte, Metadaten rechts DEC_LAYOUT
status: approved
decided: 2026-10-20
reason: Wie im Mockup des Viewers, mit dem Tool-Branding von danwos.
Entscheidung: Die Ordnerstruktur bleibt unverändert – monsterbrain liest sie und gibt keine vor DEC_STRUCTURE_UNCHANGED
status: approved
decided: 2026-10-20
reason: Der Ordner gehört seinem Nutzer und dessen Agenten; die App passt sich ihm an.
Entscheidung: Die Änderungsansicht arbeitet auf Ordnern; Git liefert die Änderungen, wo ein Ordner ein Repository ist DEC_CHANGES_ON_FOLDERS
status: approved
decided: 2026-10-20
reason: Der Wissensordner und die Code-Repositorys daneben werden auf dieselbe Weise beobachtet.
alternatives: nur der Wissensordner.
Entscheidung: monsterbrain speichert keinen Zustand über Interaktionen des Nutzers DEC_NO_INTERACTION_STATE
status: approved
decided: 2026-10-20
reason: Gesehen, gelesen und erledigt sind Review-Status – ein Feature von deciwa, das mit der deciwa-Erweiterung kommt.
alternatives: ein eigener Status „gesehen“ in der App.
Entscheidung: Claude steuert die App über einen lokalen MCP-Server; ein Chat in der App kommt später DEC_CLAUDE_MCP
status: approved
decided: 2026-10-20
reason: Am meisten für den geringsten Aufwand, ein einziger Ort zum Chatten, funktioniert mit jedem MCP-fähigen Agenten, kein API-Key in der App.
alternatives: ein Chat-Panel in der App (eingebettetes Terminal oder Agent SDK).

Agent-Aktionen¶

Entscheidung: Agent-Aktionen gehen an die laufende Claude-Code-Sitzung DEC_AGENT_RUNNING_SESSION
status: approved
decided: 2026-10-22
reason: Du und Claude arbeitet gemeinsam am Ergebnis, mit dem Chat-Kontext der Sitzung.
alternatives: eine neue Hintergrundsitzung pro Aktion, MCP-Prompts als Slash-Befehle, den Prompt kopieren.
Entscheidung: Agent-Aktionen werden nur von Hand gestartet DEC_AGENT_BY_HAND
status: approved
decided: 2026-10-22
reason: monsterbrain bietet an (Knopf, Taste), du entscheidest; kein Ereignis – etwa ein abgeschlossenes Review – startet einen Agenten.
alternatives: den Agenten automatisch starten, wenn ein Review abgeschlossen ist.
Entscheidung: „Start Claude here“ reicht, damit Agent-Aktionen einfach sind DEC_START_CLAUDE_HERE
status: approved
decided: 2026-10-22
reason: Ein Klick, wenn keine Sitzung zuhört; das Startskript und der Channel-Schalter bleiben verborgen.
alternatives: ein Einrichtungsknopf mit einem kurzen Befehl, ein eingebettetes Terminal in der App, ein Claude-Code-Plugin.
Entscheidung: Allgemeine Teile in monsterbrain, die Review-Aktion in deciwa, kein zusätzlicher Review-Zustand DEC_AGENT_GENERIC
status: approved
decided: 2026-10-22
reason: monsterbrain kennt Sitzungen und Konzepte, deciwa kennt das Review; jeder Review-Eintrag hat eine Erstellungszeit, so findet Claude selbst, was neu ist, und deciwa braucht keine Dateien pro Person.
alternatives: die Aktion fest in monsterbrain; deciwa speichert, wann der Agent zuletzt informiert wurde.

Technik¶

Entscheidung: Electron mit TypeScript DEC_ELECTRON
status: approved
decided: 2026-10-20
reason: Dasselbe Chromium auf jedem System, damit HTML-Ausgaben wie in Chrome aussehen; Linux ist stabil; eine Sprache für UI und Core.
alternatives: Tauri – viel kleinerer Download und weniger RAM, aber je Betriebssystem eine andere Web-Engine (WebKitGTK unter Linux) und Rust als zweite Sprache.
Entscheidung: Zwei Repositorys: die App und später das teilbare Brain-Setup DEC_TWO_REPOS
status: approved
decided: 2026-10-20
reason: Das Setup (Ordnergerüst, AGENTS.md, Vorlagen, Skills, Beispielbereich) wird für sich geteilt; die App wird später verteilt.
alternatives: ein Repository.
