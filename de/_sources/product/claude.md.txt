# Working with Claude

monsterbrain and Claude Code work in both directions.

## Claude steers the window

While monsterbrain runs, Claude can see what you have open and show you what
it talks about ({need}`DEC_CLAUDE_MCP`):

- open a file and **highlight the passage** it refers to,
- switch to the **change view** after its work and open a diff,
- read which file and which text you have selected – "explain this" works
  without copying anything,
- open another folder, e.g. a code repository.

```{figure} ../_static/screens/claude-highlight.webp
:alt: A Markdown file in which Claude highlighted one sentence

Claude opened the file and highlighted the sentence it is talking about.
```

Extensions add their own tools – deciwa, for example, lets Claude read your
feedback and show its state.

## The window hands work to Claude

`Ctrl Shift A` sends "explain this file", with the selected text, to Claude.
The Claude button in the head of a file implements or closes its concept or
backlog task, or sends a message of your own.

The action goes to the Claude Code session that works on that concept – in
the Claude desktop app or in a terminal. With no session open, monsterbrain
opens a new one in the desktop app with the request filled in.

Setup for both: [Claude Code](../integrations/claude-code.md).
